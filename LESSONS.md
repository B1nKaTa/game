# Lessons

- 2026-11-02: A signal connected to a lambda that captures self made a RefCounted cycle and printed exit-time leak warnings → connect the signal's own callable, like changed.emit, instead.
- 2026-11-02: Task 6 brief connected Player to health.died with a lambda capturing self, which the existing lesson forbids → copy briefs through LESSONS.md first and connect the signal's own callable (died.emit).
- 2026-11-02: Piping tools/test.ps1 through tail hid its failing exit code during a RED check → read the summary line ("N tests, M failed") or keep the real exit code before piping.
- 2026-11-02: Passing bash-style /c/... paths into a PowerShell System.Drawing Save failed with a GDI+ error → use C:\ paths when PowerShell calls Windows .NET APIs.
- 2026-11-02: The opening's full-screen ColorRect (default mouse_filter STOP) swallowed mouse clicks so _unhandled_input never saw `attack` → set mouse_filter = IGNORE on decorative full-screen Controls (backgrounds, hints) that sit over scenes using _unhandled_input.
- 2026-11-02: Setting global_position on a Node2D before add_child set the local position instead, so a thrown cane spawned far outside the room → add the node to the tree first, then set global_position.
- 2026-11-02: A physics probe must put the arena where the headless mouse (0,0) lies in the aim direction, since the player aims at the mouse → offset the arena instead of faking input.
- 2026-11-02: A thrown cane measured its flight from 32-bit Vector2 positions, so rounding stalled it just short of its range and it never dropped → track distance in a float and never use position deltas to decide when movement ends.
- 2026-11-02: A parse error in tools/smoke_driver.gd (a stray form feed from a PowerShell escape) made tools/smoke.ps1 hang forever instead of failing, because the autoload failed to create the driver → if smoke runs far past its usual minute, run Godot directly with output redirected and read the first error; and in PowerShell strings use `n and `t, never a backtick before f.
- 2026-11-02: Engine.time_scale = 0 still runs physics ticks, only their delta becomes 0, so a probe counting physics frames wrongly showed no freeze → measure a freeze by summing _physics_process delta, and time hit stop with Time.get_ticks_usec in _process.
- 2026-11-02: A flying coin that pays on arrival can be lost when the room is freed or the player dies mid-flight → pay when the flight starts and make the flight cosmetic.
- 2026-11-02: Decorative nodes under a room that is set to PROCESS_MODE_DISABLED at run end freeze mid-animation → give effects like DeathBurst process_mode ALWAYS.
- 2026-11-02: Swings tested only the enemy's center on one frame while the arc showed for 0.1 seconds and followed the mouse, so attacks visibly passed through enemies → hit tests use what the player sees: the whole body, for as long as the attack is drawn, where it is drawn.
- 2026-11-02: A probe's first section printed "damaged=false" only because nodes added in SceneTree._initialize had not run _ready and the swing crashed first → start probes with call_deferred, and include a control case that must succeed.
- 2026-11-02: PixelLab template walks dropped the cane and v3 animations came out larger than template ones, so Grandpa changed size between animations → use v3 for every animation of a character and say in each prompt that he grips the cane in every frame.
- 2026-11-02: Mapping generated sprites to the small project palette put orange streaks in Grandpa's hair and muddied his trousers → compare raw and palette versions enlarged before enforcing a palette.
- 2026-11-02: The attack animation stopped after the 0.1 second hit window and a 10 FPS loop showed about one frame → time a one-shot animation by its own duration, separate from the hit window.
- 2026-11-02: Doors fire on proximity, so arriving on a return door would bounce the player straight back → a door only works after the player has stepped out of its range.
- 2026-11-02: Keeping visited rooms alive out of the tree keeps pickups simply, but anything mid-flight resumes on return and nothing frees those rooms automatically → clear shots, bursts and flying coins on leaving, and free rooms in the scene's _exit_tree.
- 2026-11-02: A probe's simulated E press did nothing because it ran right after a screenshot, which is after that frame's _process, so just_pressed had already passed → await process_frame before simulating input, and suspect the probe's timing before the game.
- 2026-11-02: A probe that hits a script error never reaches quit() and hangs until the tool times out → give every probe a timer that quits with an error.
- 2026-11-02: Probes that ran the real floor scene without --smoke added Pension to the player's real save.json → back up and restore save.json around any probe that runs real scenes, and read the save before and after.
- 2026-11-02: A boss's summons paid Pension, so leaving it alive allowed endless farming → anything that can spawn without limit must pay nothing.

- 2026-11-02: A sed range starting at a pattern that appears twice deleted to the end of door.gd because its second start never found an end → read the diff after any sed range delete, and prefer exact line edits.
