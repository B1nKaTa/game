# Endings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the one-off `EndingCard` with eleven endings chosen from what the run did, each played as a short code-drawn puppet show, plus Augustine's side scene, an Ending Archive, rewards and Gerald in the Lobby.

**Architecture:** A pure `EndingRules` picks an ending id from a run snapshot that `RunState` builds from run-only fields. Each ending is a data list of steps (`scripts/content/endings/<id>.gd`) that a `CutscenePlayer` (a `CanvasLayer`) plays over whatever scene is current, with a `CutsceneStage` drawing the set and `CutsceneActor`s (Harold's real sprite, everyone else drawn by `ActorLook`) acting it out. The player is stepped by `advance(delta, pressed, skip_held)`, so tests drive it frame by frame without input or autoloads.

**Tech Stack:** Godot 4.7.2, GDScript, the project's own headless test runner (`tools/test.ps1`) and full-loop driver (`tools/smoke_driver.gd`).

## Global Constraints

- Never name another game anywhere (files, comments, asset names, commits).
- No new dependencies or add-ons.
- Old saves load. Every new save field is optional with a fallback. `ending_seen = true` with no `endings_found` means `endings_found = {"briefly_alive": true}`; keep writing `ending_seen`.
- Run-only tracking lives in `RunState` and is never saved in Progress.
- Tone: dark comedy in the voice of `scripts/scenes/opening.gd`; tighten the draft lines, keep every joke.
- Each ending scene lasts 25 to 45 seconds; ending 11's deaths 5 to 8 seconds.
- Any key or click moves the current text on; holding interact for 1 second skips; the first time an ending plays, the skip is offered only after the first text box.
- Every scene ends: a cause-of-death `card`, a fade, the Waiting Room with "Welcome back. Please take a number."
- `ENDING_CONDOLENCES` = 15 the first time each ending is found. `eternal_feud` also gives Gerald's Hat (hat slot, owned at once).
- Panels have an opaque backing and fit 640x360. Text that must be read sits on the HUD layer.
- Game files keep CRLF; Write-tool files get a CRLF pass; never PowerShell `Set-Content`/`Out-File` on game files.
- Tests never load scene scripts that name autoloads; anything a test calls lives on a core class or a script that names no autoload.
